# Локальный запуск текущего приложения

Этот файл описывает **нынешний код**, а не целевой исследовательский конвейер из `mvp-development-plan.md`. В приложении пока нет запуска гипотез, оценок или фонового сбора котировок. Профили `sandbox` и `prod` выбирают контур T-Invest; слово `prod` означает реальный API, а не реальные сделки. Текущий `TInvestClient` содержит запросы рыночных данных и справочника, без методов выставления заявок.

Для сетевого запуска задайте токен выбранного контура. Для работы с реальными рыночными данными используйте токен с минимально необходимыми правами, по возможности только для чтения. Не записывайте токен в `application*.yml`, аргументы запуска или файлы репозитория.

## Запуск из IntelliJ IDEA

Создайте **необщую** Run Configuration для `AnalystApplication` (тип Spring Boot или Application):

1. В конфигурации Spring Boot укажите `Active profiles: local,prod`; для обычной Application-конфигурации добавьте program argument `--spring.profiles.active=local,prod`.
2. В `Environment variables` добавьте `T_INVEST_TOKEN` со значением самого токена, без префикса `Bearer`.
3. Не включайте `Store as project file`/`Share through VCS` для конфигурации с секретом.

Это самый простой локальный вариант, но значение хранится на вашем компьютере в конфигурации IDE в открытом виде. `.idea/workspace.xml`, `.idea/runConfigurations/` и `.run/` исключены из Git в `.gitignore`; перед публикацией проекта всё равно проверяйте состав файлов. Для более строгого хранения можно позже подключить macOS Keychain, но это потребует отдельной интеграции приложения.

## Запуск из терминала

Задайте токен в окружении текущей shell-сессии. Не помещайте его в командную строку или историю shell.

```shell
read -s 'T_INVEST_TOKEN?T-Invest token: '
export T_INVEST_TOKEN
echo
./gradlew bootRun --args='--spring.profiles.active=local,prod'
```

Для песочницы заменить `prod` на `sandbox`. Профили взаимоисключающие; по умолчанию контур не выбран. `local` задаёт SQLite-файл `drv-analyst.sqlite` относительно рабочей директории. Файлы `*.sqlite` и `.env*` игнорируются Git; `.env.example` содержит только имя переменной.

Feign-клиент проверяет TLS-сертификат T-Invest по `src/main/resources/tbank.ru.pem` и имя сервера стандартным hostname verifier. Файл содержит сертификат сервера `*.tbank.ru`, действующий до **24 августа 2027 года**; при его замене T-Invest потребуется обновить PEM. При отсутствии или пустом `T_INVEST_TOKEN` приложение не создаёт клиент с пустым заголовком Authorization. Для HTTP 5xx и сетевых таймаутов разрешены максимум три попытки, остальные ошибки не повторяются. Сам запуск приложения не делает пробный запрос к T-Invest: расписание запрашивается только вызовом соответствующего сервиса. Обычный `./gradlew test` выполняется без сети и токена.

## Ротация ранее опубликованного токена

1. Отозвать ранее опубликованный токен в кабинете T-Invest.
2. Создать новый токен с минимально необходимыми правами для выбранного контура.
3. Передавать его приложению через `T_INVEST_TOKEN`.
4. Убедиться, что старый токен больше не принимает запросы.

Целевой Forward Testing требует read-only подключения к реальному API. Текущий запуск ещё не создаёт и не оценивает наблюдения. Фоновый сбор истории стакана в первом MVP не планируется: стакан сохраняется при анализе выбранной серии.
